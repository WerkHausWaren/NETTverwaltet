# Sicherheitslücken melden

Danke, dass du hilfst, NETTverwaltet sicher zu halten. In der Software stehen die Daten echter Vereinsmitglieder.

**Bitte melde eine Sicherheitslücke nicht als öffentliches Issue.** Nutze stattdessen die vertrauliche Meldung von
GitHub: Reiter **„Security“** → **„Report a vulnerability“**. Nur die Betreuer:innen des Projekts sehen deine Meldung.
Geht das nicht, schreib eine E-Mail an **r.marx@werkhauswaren.de** mit dem Betreff „Sicherheit“.

Hilfreich sind:

- was genau das Problem ist und welche Version betroffen ist,
- wie man es nachstellen kann (Schritte, Beispiel-Anfrage),
- was jemand damit anrichten könnte.

Wir antworten so schnell es ehrenamtlich geht, in der Regel innerhalb einer Woche, und melden uns, sobald es eine
Korrektur gibt. Bitte gib uns Zeit, die Lücke zu schließen, bevor du sie veröffentlichst.

Teste nur mit deiner eigenen Installation oder der Demo (https://verein.nettverwaltet.de) – nie mit den Daten
anderer Vereine.
