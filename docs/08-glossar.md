# Kleines Technik-Wörterbuch

**Browser** – das Programm, mit dem ihr Internetseiten öffnet, z. B. Firefox, Chrome, Safari oder Edge.

**Server (VPS)** – ein Computer in einem Rechenzentrum, der rund um die Uhr läuft. Ihr mietet ihn bei einem Anbieter
und erreicht ihn über das Internet. VPS heißt „virtueller privater Server“: ein eigener Bereich auf einem großen Rechner.

**Ubuntu** – ein kostenloses Betriebssystem für Server (wie Windows oder macOS, aber für Server üblich).

**Domain, Subdomain** – eure Internetadresse, z. B. `euer-verein.de`. Eine Subdomain ist ein Teil davon, z. B.
`verwaltung.euer-verein.de`.

**DNS, A-Eintrag** – das „Telefonbuch“ des Internets. Ein A-Eintrag sagt: Diese Adresse gehört zu jenem Server
(seiner IP-Adresse).

**IP-Adresse** – die Nummer eines Rechners im Internet, z. B. `203.0.113.10`.

**Terminal, PowerShell** – ein Fenster, in dem man Befehle eintippt statt zu klicken. Auf dem Mac heißt es
„Terminal“, unter Windows „PowerShell“.

**SSH** – sichere Verbindung von eurem Rechner zum Server. Mit `ssh root@IP-ADRESSE` tippt ihr danach Befehle direkt
auf dem Server.

**root** – das Hauptkonto auf einem Linux-Server mit allen Rechten.

**Docker, Container** – Docker packt ein Programm mit allem, was es braucht, in einen „Container“. So läuft es auf
jedem Server gleich, ohne dass ihr viel installieren müsst.

**HTTPS, Zertifikat** – verschlüsselte Verbindung zwischen Browser und Server (das Schloss in der Adresszeile). Das
Zertifikat dafür kommt kostenlos von „Let's Encrypt“; der Server holt und erneuert es selbst.

**SMTP** – die Art, wie Programme E-Mails verschicken. Die Zugangsdaten bekommt ihr von eurem E-Mail-Anbieter.

**Backup, Sicherung** – eine Kopie eurer Daten, um sie nach einem Fehler wiederherzustellen.

**Cron** – ein Zeitplaner auf dem Server, der Aufgaben automatisch ausführt, z. B. jede Nacht eine Sicherung.

**Git, GitHub** – Git verwaltet die Versionen eines Programms. GitHub ist die Website, auf der NETTverwaltet liegt.
`git clone` holt eine Kopie, `git pull` holt Updates.

**Release** – eine fertige, veröffentlichte Version der Software, z. B. „v1.0“.

**FinTS** – die Schnittstelle deutscher Banken für Online-Banking-Programme.

**SEPA-Lastschrift** – der Einzug von Beiträgen vom Konto der Mitglieder, mit deren Erlaubnis (Mandat).

**Zwei-Faktor-Anmeldung** – neben dem Passwort braucht ihr einen zweiten Nachweis, z. B. einen Code aus einer
App auf dem Handy. Das schützt, falls ein Passwort in falsche Hände gerät.

**Passkey, Face ID** – Anmeldung per Gesicht oder Fingerabdruck statt Passwort.

**AGPL** – die Lizenz von NETTverwaltet: frei nutzbar und veränderbar; wer eine veränderte Fassung für andere online
betreibt, muss den geänderten Quellcode offenlegen.
