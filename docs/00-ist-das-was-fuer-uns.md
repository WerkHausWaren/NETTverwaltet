# Ist das was für uns?

Diese Seite hilft euch in fünf Minuten zu entscheiden, ob NETTverwaltet zu eurem Verein passt.

## Für wen ist NETTverwaltet gedacht?

Für **gemeinnützige Vereine**, die ihre Verwaltung nicht mehr in Excel-Listen, Ordnern und E-Mail-Postfächern
verteilt haben möchten – zum Beispiel Kultur-, Sport-, Förder-, Heimat- oder Sozialvereine, Initiativen und
Bündnisse. Entstanden ist die Software in einem Kulturverein mit Kino, Café, Werkstätten und vielen Ehrenamtlichen.

Besonders gut passt sie, wenn ihr …

- Mitglieder, Beiträge und Kasse an einem Ort führen wollt,
- Veranstaltungen mit Anmeldung, Helfer:innen-Schichten oder Einlass organisiert,
- euren Mitgliedern eine App fürs Handy anbieten möchtet,
- Wert darauf legt, dass die Daten bei euch bleiben und nicht bei einem fremden Anbieter.

## Was kostet das?

| Posten | Kosten |
|---|---|
| Die Software | **0 €** – keine Lizenz, kein Abo, keine Kosten pro Mitglied |
| Betrieb auf dem eigenen Rechner | 0 € |
| Betrieb auf einem eigenen Server | ein kleiner Mietserver ab etwa **4–5 € im Monat**, dazu eine eigene Internetadresse (Domain) – die habt ihr vielleicht schon für eure Website |

Freiwillige Spenden an WerkHausWaren e.V., wo die Software entstanden ist, sind willkommen, aber keine Bedingung.

## Welche Betriebsart passt?

| | Auf dem eigenen Rechner | Auf einem eigenen Server |
|---|---|---|
| Wer arbeitet damit? | eine Person (z. B. Kasse oder Vorsitz) | mehrere Vorstandsmitglieder gleichzeitig |
| Von wo? | nur an diesem Rechner | von überall, auch vom Handy |
| Mitglieder-App, Anmeldungen, Online-Formulare | nein | ja |
| Anmeldung mit Passwort | nein (der Rechner ist der Schutz) | ja, mit Zwei-Faktor oder Face ID |
| Einrichtung | ca. 10 Minuten, Doppelklick | ca. 30–60 Minuten nach Anleitung |
| Technik-Kenntnisse | keine | jemand, der eine Anleitung Schritt für Schritt abarbeitet und ein paar Befehle abtippt |

Ihr könnt **klein anfangen** – erst auf dem eigenen Rechner, später auf einem Server.

## Wer im Verein sollte sich kümmern?

Für den Server-Betrieb braucht ihr **eine Person, die sich zutraut**, einer Anleitung zu folgen, ein paar Befehle
abzutippen und alle paar Monate ein Update einzuspielen. Programmieren muss niemand.
Wenn bei euch niemand dafür Zeit hat: Fragt im Umfeld – oft gibt es in Vereinen, Schulen oder Firmen jemanden,
der so etwas gern einmal einrichtet.

## Was NETTverwaltet nicht ist

- **Kein Angebot mit Kundendienst.** Die Software wird ehrenamtlich gepflegt. Hilfe gibt es über die Anleitungen und
  über GitHub, aber ohne Garantie und ohne feste Antwortzeiten.
- **Keine Steuer- oder Rechtsberatung.** Die Software hilft bei Kasse, Spendenbescheinigungen und Datenschutz – die
  Verantwortung bleibt beim Vorstand.
- **Kein fertiger Rundum-Service.** Ihr betreibt die Software selbst. Dafür gehören euch die Daten.
