❓ Wie bekomme ich die PayPal-CSV-Datei?
  1. Auf paypal.com einloggen → Aktivitäten.
  2. Zeitraum wählen → Herunterladen (oben rechts).
  3. Format CSV wählen und herunterladen.
  4. Die heruntergeladene Datei hier unten hochladen.
Die Datei bleibt nur lokal {{ 'auf diesem Server' if config.PRODUKTION else 'auf deinem Mac' }}. PayPal bietet kein FinTS – der CSV-Export ist der offizielle Weg.

{{ '⚙️ Zugang ändern' if pp_zugang_da else '⚙️ PayPal-Zugang einrichten' }}
  1. developer.paypal.com mit dem Vereins-PayPal-Konto anmelden
  2. Apps & Credentials → oben „Live" wählen → Create App (Name egal, z. B. „Vereinsverwaltung")
  3. In der App unter Features den Haken bei „Transaction Search" setzen und speichern
  4. Client ID und Secret unten eintragen (das Secret erscheint nach Klick auf „Show")
Wird verschlüsselt gespeichert. Hinweis: „Transaction Search" wirkt bei PayPal erst einige Stunden nach dem Aktivieren – „Zugang testen" zeigt dir den Stand.
